# SMART_CLASS
EDUCAM MVP-1 — это прототип платформы «Умный класс», объединяющей компьютерное зрение (камеры), динамический учебник и аналитику поведения на уроке.  Система предназначена для поддержки образовательного процесса и предоставляет учителю, родителю и администрации объективную информацию о ходе занятия в реальном времени и после его завершения.
